# 02. External methodology review fixes

Three of the changes were made within 40 seconds of each other, so they were recorded as a batch. The leakage re-runs themselves were earlier the same day: the saved console outputs in `/tmp` (grouped-CV re-runs) show this.

## Questions

1. What statistic is the 7.89 cm safety gate?
2. Are Stage 3 train/test splits independent?
3. Does the Kelvin-Voigt weak-damping assumption hold?
4. Does per-class recall collapse earlier than the aggregate floor?

## Gate statistic

The old 9.0 cm cutoff had no derivation. The nearest match, 7.89 cm, turned out to be the 5th percentile of bootstrap resample means, which bounds the population mean and says nothing about an individual unit. The worst observed seed floor is 5.45 cm, more than 3 cm under it. Replaced with 6.50 cm, the empirical 10th percentile of the 24 per-seed floors (numpy linear interpolation). The 5th percentile (5.65 cm) was rejected for sensitivity to n=24. All candidates are in `Source/logs/gate_statistic_verification.csv`, regenerated by `Source/regenerate_gate_statistic_verification.py` after another script overwrote the file mid-run. The regenerated numbers matched the earlier reported ones.

## Train/test leakage

Each raw-signal window comes from one of 90 realizations (about 4 windows each), and the flat window pool let windows of one realization land on both sides of a split. `build_raw_dataset_with_groups()` was added and splits now go by realization (GroupShuffleSplit or grouped 5-fold).

| result | before | after |
|---|---|---|
| CNN single split | 88.89% | 89.81% |
| ResNet1D single split | 90.28% | 86.11% |
| baseline 5-fold CV | 71.59% ± 3.57% | 72.70% ± 2.08% |
| CNN vs baseline p | 0.0083 | 0.0175 |
| ResNet1D vs baseline p | 0.0012 | 0.0078 |
| ResNet1D vs CNN p | 0.22 | 0.242 |

A 15x repeated grouped 5-fold run (`Source/repeated_grouped_cv_log11.py`) gave sign-flip permutation p = 0.0002 for all three comparisons. The change note flagged that the 75 differences come from 90 realizations reshuffled, so they are not independent. Lane 2 (05) later applied the Nadeau-Bengio correction. Reconciling the ResNet1D per-class metrics with the 86.11% figure took two attempts: two GroupShuffleSplit call sequences gave the same 54/18/18 counts from different group assignments, and matching the 0.4/0.5 proportions in `gradcam_resnet.py` reproduced 86.11% exactly.

## External review script batch

- Per-class recall on seed 121 (the only CNN with saved weights): cirrhosis and fibrosis recall reach near chance 1 to 1.5 cm shallower than the 8.48 cm aggregate floor. Healthy stays above 97%. Margin to the 6.50 cm gate: +0.5 cm and +1.0 cm. This single-seed result started the per-class question that Lane 5 (09) later ran across 24 seeds.
- Frozen-embedding linear probe at 8.18 cm: 100% held-out accuracy on the 32-d embeddings against 33% for the deployed head (`Source/logs/frozen_embedding_linear_probe_8p18cm.csv`).
- Grad-CAM occlusion: occluding the flagged region drops confidence by 0.31 to 0.44 against 0.007 for a control region; 77% of pulse-timing shifts flip the predicted class (`gradcam_counterfactual_occlusion.csv`). Run on the Log 08 ResNet1D, the only one with saved weights at the time.
- Weak-damping check: omega·eta/G is not small at 250/500 Hz for any class, and cirrhosis is borderline at 100 Hz. Leading-order error bound derived analytically (6 to 30% on alpha at 250 Hz). Lane 1 (04) later replaced this with the exact solution.
- The original Log 11 5-fold restart count was never written to a file and is unrecoverable.
